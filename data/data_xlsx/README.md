# ARID datasets — Excel (`.xlsx`) copies

This folder contains ready-to-download Excel copies of the five ARID datasets
(`arid_humans`, `arid_animals`, `arid_plants`, `arid_sites`, `arid_c14`), kept in
sync with the `.rda` objects bundled in the R package. They are provided so the
data can be inspected or reused without an R installation.

## ⚠️ Please cite if you use these data

If you use any of these datasets in a publication, presentation, or derived
work, **please cite the repository**:

> Mayorga, D. (2026). *ARID: Atacama Repository of Isotopic Data.*
> https://github.com/mayorgarmijo/arid

Whenever possible, **also cite the original data source** of the specific
records you use. Each row carries its provenance in the `reference_short` and
`doi` columns — please credit those primary studies as well.

## Notes

- These `.xlsx` files are copies for convenience; the authoritative version of
